# Unified Core contract matrices

These tables are the executable/detail layer of `core-adr.md`; they do not create a second architectural decision. “Zero mutation” means no aggregate, world, audit/domain, outbox, projection, or cursor change, except a durable rejected command result where R4 admission has begun.

## M1. Exact end-to-end turn

| Order | Boundary / authority | Input and checks | Durable effect | Versions / identity | Failure and retry oracle | Projection consequence |
|---:|---|---|---|---|---|---|
| 0 | Browser surface | Table sends a normal action or approved draft; scene is read-only; admin sends only operational controls. | None. | Client creates stable `command_id`; approval also carries `turn_id`, `draft_version`, and one-use nonce. | A resend is byte-for-byte the same logical command. A different surface cannot manufacture table authority. | None before admission. |
| 1 | Transport/static admission | Authenticate room membership and surface capability, validate envelope/schema/body limit, bind server-owned `room_id`, actor and surface. Never accept client-supplied role/room authority. | None. | Server namespace is `(room_id, command_id)`. | Invalid token, wrong room/surface, oversized or malformed body: reject before the R4 transaction and write no game/result row. | No player bytes. |
| 2 | R4 command transaction: dedupe first | Look up `(room_id, command_id)` and compare the canonical request digest. | Exact duplicate returns the stored safe result; conflicting digest returns `command_id_conflict`. | Same ID+same digest is retry; same ID+different digest is conflict. | Both paths cause zero additional world/audit/outbox mutation. This precedes dynamic actor/version checks. | Stored result is safe-summary only; it contains no secret plan/model output. |
| 3 | Dynamic authorization | Load the current pinned room aggregate; check actor remains eligible, command is allowed from this surface, and the room is not paused/ended. | Rejection result only. | Current membership/capability, not a stale browser claim. | Unauthorized new ID is durably rejected with zero world mutation. A previously committed duplicate still returns its stored result. | No new projection task for rejection unless an allowlisted operational error is needed. |
| 4 | Optimistic/stage admission | Check expected aggregate version; command-specific draft/plan/provider-attempt/pending-roll/combat cursor; lifecycle transition and nonce. | Rejection result only. | One aggregate version is authoritative; no independent story/tactical version. | Stale draft, stale version, consumed nonce, wrong pending roll or wrong stage: zero world mutation. | Current safe snapshot remains. |
| 5a | Standard resolver (pure) | Resolve legal target/cells, LOS/range, action/resource budget, authored/rules references and deterministic roll requirement. | Produces a closed `ResolutionPlan(kind=standard)` only. | Plan records definition/rules hashes, actor, expected version and resolution references. | Illegal/unsupported standard action yields no plan and no mutation. | None. |
| 5b | Coordinator + private adjudicator (pure candidate producer) | Coordinator first commits `provider_attempt_id=running`, then dispatches bounded visible state, necessary secret facts, typed rules/tool schemas and the approved unusual intent. | Attempt identity/status is durable before external work; adjudicator produces a candidate `ResolutionPlan(kind=unusual)` only. | Candidate is accepted only for the exact current `turn_id`, `draft_version`, plan digest inputs and running provider attempt. | Text, unknown operation, free-form patch, invented ID/rule or plan mismatch is durably rejected; a cancelled/replaced/late provider event cannot mutate. | Model prose is never public narration. |
| 6 | Deterministic validator | Re-run all references, reveal eligibility, range/LOS/resources, resolution bindings, operation preconditions, cross-operation invariants and ending rules against the same loaded snapshot. | None until the complete plan validates. | Exact pinned definition/rules hashes and expected aggregate version. | Validation is detached/all-or-nothing: failure in operation N leaves effects 1…N−1 unapplied. | None. |
| 7 | Game kernel + R4 atomic commit | Apply reducers; evaluate consequences/endings; store aggregate, command result, audit/domain rows, and projection outbox in one transaction. | One committed aggregate transition. | `aggregate_version` increments for every durable workflow/control/world change; `world_revision` only for canonical game/presentation state changes. | Crash before commit rolls back all. Crash after commit returns stored result and schedules only unfinished delivery. | Projection outbox references the committed version and hashes. |
| 8 | Positive projector | Load exact committed aggregate and pinned inputs. Build full table/scene/admin projections independently; build narrator `PresentationBundle` separately; validate closed shapes and outer/nested version equality. | Store projection batch; no world mutation. | Same `projection_batch_id`, aggregate/world versions and definition/rules hashes across the family; equality is enforced by a mandatory cross-field validator in addition to JSON Schema. | Any mixed version, unsafe/unknown field or secret canary fails publication closed; last safe UI stays visible. | Only allowlisted fields described in M5. |
| 9 | Broker/browser render | Deliver full snapshot, then optional ephemeral deltas. Browser validates room/surface/version and renders atomically. | Cursor advances only after render acknowledgement. | Stable batch/event IDs; monotonically acknowledged committed sequence. | Disconnect/reconnect requests last acknowledged cursor then receives a full current snapshot. Render failure cannot acknowledge/skip the batch. | Reprojection is delivery-only and cannot repeat kernel mutation. |
| 10 | Narration/audio boundary | Narrator sees only persisted safe `PresentationBundle`; output is stored with `presentation_id/line_id/context_id` before TTS. | Presentation/audio delivery state only. | Audio identity is independent of command identity but points to one committed presentation. | Cancel stops provider generation and buffered browser playback separately. Retry/replay never re-executes the game command. | Table/scene may show text-only degradation. |

## M2. Typed operation algebra and disposition of the old seven primitives

The operations below are internal `ResolutionPlan` effects. They are not browser/model RPC methods. An accepted intent selects a resolver; only the kernel applies operations.

| Old primitive / required semantic | Disposition | Canonical internal operation | Required server validations | Structured result / domain evidence | Player-safe projection |
|---|---|---|---|---|---|
| `move` | Keep, narrow | `move_entity` | Existing visible/controllable entity; canonical path; adjacency; occupancy; walls; difficult-terrain cost; movement budget; phase eligibility. | Exact path, spent movement, final cell. | Token path/final cell and remaining visible movement. |
| `damage` | Replace as free numeric command | `apply_damage` | Existing target; exact op/target/amount/type must equal an unconsumed `resolution_effect_id` authorized by the stored resolution; resistance/immunity/temp HP; no client/model-authored arbitrary damage. | Source, resolution/effect IDs, one-time consumption, raw/applied damage, HP/temp-HP delta, downed/death transition. | Public roll/modifier/result and player-visible HP/status policy. |
| Healing (missing) | Extend | `apply_healing` | Stored resolution/effect; max HP; target eligibility; death-state rules. | Applied healing, HP delta, downed/stable reset. | Visible HP/status change. |
| Conditions (missing) | Extend | `set_condition` | Condition in curated ruleset; legal source/target/duration/stacking; resolution/effect reference. | Add/remove/refresh with source and expiry. | Allowlisted condition icon/duration. |
| Resource use (missing) | Extend | `spend_resource` | Resource defined by hero/ruleset; sufficient balance; action phase; once-per-turn/rest constraints. | Before/after amount and reason. | Player-safe remaining uses/action economy. |
| `create_effect` | Keep, narrow | `create_effect` | Effect template from pinned definition/ruleset; bounded area/duration/source; LOS/target and stacking rules. | Effect instance ID, cells/entities, expiry. | Visible template/area only when public. |
| `change_terrain` | Replace | `set_terrain_feature` | Existing authored cell/edge/feature or whitelisted semantic template; transition allowed; never arbitrary map JSON. | Feature ID, old/new semantic state, movement/LOS consequences. | Updated public cell/edge/light state. |
| `spawn` | Replace | `spawn_from_template` | Exact pinned template; allowed authored spawn anchor/cell; unique entity ID assigned server-side; occupancy/visibility. | Template/entity IDs and spawn cell. | Visible token only if revealed. |
| `remove` | Replace | `despawn_entity` | Explicit removable class/reason; never deletes a hero/NPC death/history/immutable truth; lifecycle rules precede despawn. | Entity becomes absent/despawned with reason; history retained. | Token disappearance plus safe reason if perceivable. |
| NPC presence/death (missing) | Extend | `set_npc_status` | Allowed transition among `alive_present`, `alive_absent`, `dead`; authored immortality/death rules; carrier reachability recomputed. | Old/new lifecycle and invalidated route eligibility. | Only observable status/presence; no secret carrier graph. |
| `reveal` | Replace | `reveal_fact_via_route` | Exact fact and route exist; route eligible now; route contains fact; conclusion included; audience allowed; immutable truth untouched. | Ledger entry `{fact_id, route_id, audience, command_id, world_revision}`. | Authored `public_fact`, never private `truth` or secret IDs. |
| Time/threats (missing) | Extend | `advance_clock` | Authored clock; monotonic bounded delta; trigger thresholds evaluated deterministically. | Clock delta, crossed thresholds, newly eligible consequences. | Public clock/threat changes only where authored visible. |
| Deferred consequence (missing) | Extend | `schedule_consequence` | Pinned consequence template; server derives instance identity from template + causal command/transition; candidate cannot supply an instance ID or generic payload. | Durable scheduled record; retry reuses the cause identity and firing consumes once. | Public foreshadow/result atoms only if authored. |
| Physical roll request (missing) | Extend | `open_physical_roll` | One unresolved check; actor/die/modifier/reason/DC/AC/resolution context server-owned; no concurrent conflicting pending roll. | Immutable pending-roll record. Confirmation is a separate command that creates one immutable resolution and consumes it once. | Pending-roll card, confirmed face/modifier/total/result. |
| Combat scheduler (missing) | Extend | `advance_combat_mode` | Mode-specific phase/cursor, eligible actors, acted set, resource resets; encounter mode locked after first action. | Phase/cursor/round transition and acted/resource reset. | Current mode, phase/order/active/acted set. |

`core-contract.schema.json#/$defs/Operation` is the mechanical minimum for these names and closed argument shapes. R9 must enumerate every authored unusual beat; an uncovered need adds a named semantic operation and oracle, never a generic patch operation.

## M3. Six level-3 starter profiles

These are rule-coverage profiles, not final names, prose, balance or art. All prepared choices must come from SRD 5.2.1 or independently authored content with recorded provenance.

| Profile ID | SRD class / subclass baseline | Table role | Minimum features/resources that force coverage | Excluded from the core decision |
|---|---|---|---|---|
| `guardian` | Fighter / Champion | Durable front line | Fighting style, Second Wind, Action Surge, improved critical; weapon range, attack/damage and one-per-rest resources. | Final ability scores/equipment/name/portrait. |
| `fury` | Barbarian / Berserker | Risk/reward melee | Rage uses, resistance/damage modifier, Reckless Attack, Danger Sense, Frenzy choice and condition interaction. | Final tuning of Frenzy drawback. |
| `shadow` | Rogue / Thief | Mobile skill striker | Expertise, Sneak Attack eligibility, Cunning Action, Fast Hands/Second-Story Work; advantage/adjacency and bonus action. | Full object-interaction catalogue. |
| `beacon` | Cleric / Life Domain | Support/healing | Prepared spells/slots, spell save/attack, Channel Divinity, Disciple of Life, concentration, healing/downed interaction. | Full cleric spell list. |
| `arcanist` | Wizard / Evoker | Area/control caster | Prepared spells/slots, Arcane Recovery, Sculpt Spells, areas, saves, concentration and effect templates. | Ritual/scribing economy and full spell list. |
| `voice` | Bard / College of Lore | Skill/support/control | Bardic Inspiration, Jack of All Trades, Song of Rest, Expertise, Cutting Words reaction, spell slots/concentration. | Full social simulation and full spell list. |

## M4. Minimum `srd-5.2.1-mvp-1` rules closure

| Required category | MVP rule closure | Named oracle class | Explicitly outside the minimum |
|---|---|---|---|
| Core d20 | Ability modifiers, proficiency (+2 at level 3), checks/saves/attacks, advantage/disadvantage, critical hit/failure rules where applicable. | Fixed RNG vectors and exact modifier/result breakdown. | Every optional rule and every skill interaction not used by a starter/slice. |
| Turn economy | Action, bonus action, reaction, movement; per-turn/per-round/per-rest resources; legal target selection. | Same action/resource cannot be spent twice; rejected action has zero mutation. | Generic automation for all SRD classes. |
| Square grid | 5-foot cells, integer positions, occupancy, shortest valid range, difficult terrain, diagonal corner blocking, authored walls/edges. | Golden paths, blocked corner, occupied cell, exact remaining movement. | 3D movement, hexes, physical miniature tracking. |
| Sight/range/cover | Deterministic LOS against authored blockers; range; visible target; cover categories only where the slice uses them. | Symmetric LOS fixtures, hidden target rejection, boundary-range tests. | Vision physics beyond authored 2D rules. |
| HP/results | Attack/save resolution, damage types used in slice, temp HP, resistance/immunity/vulnerability used in slice, healing and 0 HP. | Fixed roll vectors; damage/healing bind to immutable resolution. | Unsupported damage types/features silently approximated. |
| Death | Physical death-save pending rolls; success on 10+, natural 1 = two failures, natural 20 = 1 HP, three successes stable, three failures dead. | Transition table including duplicate confirmation and healing reset. | Secret fudging or automatic survival. |
| Conditions/effects | Only conditions and durations referenced by the six prepared heroes and authored encounters; explicit stacking/expiry. | Table-driven add/remove/refresh/expiry cases. | Pretending unimplemented SRD conditions work. |
| Spells/areas | Curated prepared spell subset; slots; spell attack/save DC; area templates; concentration; legal targets; authored effect semantics. | One golden case per prepared spell/effect plus concentration replacement/break. | Full SRD spell catalogue. |
| Initiative | `side_phases` scheduler and `classic_initiative` fallback over identical entities/resources/commands. | Equivalent legal action in both modes; mode cannot change mid-encounter; deterministic cursor. | Claiming side phases are balanced before R10. |
| Rest/reset | Only reset cadence needed by prepared resources and 60–90-minute slice. | Exact before/after resource fixtures. | Long-term campaign economy beyond the slice. |
| Content/license | Bundle pins exact SRD version and includes the official SRD 5.2.1 attribution; independently authored additions have provenance. | Manifest/attribution delivery check. | Mixing SRD 5.1 semantics or D&D setting/branding by implication. |

## M5. Projection and narration allowlists

| Consumer | Positive inputs | Explicit exclusions | Write capability | Failure/reconnect behavior |
|---|---|---|---|---|
| Table | Public board geometry/cells/tokens; legal-action hints; allowed HP/status/resources; combat phase/order/acted set; pending and public rolls; action card with turn/draft/plan digest, nonce, declared costs/check/stakes and visible effects; public events; TTL planning overlays. | Full definition; private truth/fact IDs; typed plan operations/model I/O; raw transcript history; admin recovery internals; hidden entities/terrain. | Table commands only through transport/R4 admission; overlays are ephemeral and never canonical. | Full latest safe snapshot after reconnect; overlays expire/rebroadcast by overlay IDs, not world replay. |
| Scene | Current authored public scene/portrait/speaker; safe subtitle/presentation atoms; listening/thinking/speaking status; major public results. | Tactical hidden state; approval capability; private facts/prompts/transcripts; admin diagnostics. | Read-only. | Last safe scene remains; newer full snapshot replaces atomically. |
| Admin | Room lifecycle status; stage/version/IDs; provider/connection health; safe error codes; mic/audio diagnostics and volume; cancel/reproject controls. | Campaign truth/secrets; private model prompt/output; raw player transcript history; player-safe fields are not automatically admin-visible. | Operational commands only: start/pause/end, diagnostics, volume, cancellation, safe reproject/retry. No creative/world override. | Reproject/retry references committed batch/presentation; never reruns the command. Pause resolves to a named coordinator state. |
| Narrator (server internal) | Persisted `PresentationBundle`: authored revealed `public_fact`, visible sensory results, public rolls/results and allowlisted safe atoms. | Private adjudicator context/output; unrevealed facts; full aggregate/definition; raw transcript; admin data. | Produces one line bound to persisted presentation only; no game tools. | Unsafe bundle fails closed; text-only template fallback can present the committed result. |

## M6. Adversarial/failure oracle matrix

| Fault / attack | Injection point | Required observed result | Forbidden result | Probe/test owner |
|---|---|---|---|---|
| Exact duplicate | Before and after commit with same ID/digest | Same stored result and versions; one mutation/event/outbox set. | Re-execution, new roll or new narration mutation. | Durable coordinator/kernel. |
| Conflicting ID | Same `(room, command_id)`, changed digest | `command_id_conflict`; zero additional mutation. | Treating changed body as retry. | Admission. |
| Dynamic auth changed | Actor loses control after original commit | Exact duplicate still returns stored safe result; new command rejects. | Dedupe after current authorization or leaking old private result. | Admission/security. |
| Wrong surface/session | Scene/world command, client-forged room/role | Pre-transaction rejection; no result/world row. | Trusting payload authority. | Transport/security. |
| Stale version/draft/nonce | Before plan execution | Durable rejection; zero world mutation. | Partial plan or accepting old approval. | Coordinator. |
| Crash before commit | At every write boundary inside transaction | All aggregate/result/event/outbox writes absent. | Partial narrative/tactical/roll state. | Persistence. |
| Crash after commit/before response | Response boundary | Retry returns stored result; recovery delivers projection only. | Whole-turn replay. | Persistence/recovery. |
| Operation N fails | Multi-operation unusual plan | Detached validation rejects complete plan; state hash unchanged. | First N−1 effects visible. | Kernel. |
| Late provider event | Old `provider_attempt_id` after redraft/cancel/commit | Current running attempt is loaded from durable coordinator state; mismatch is durably rejected/audited with zero mutation. | Request-provided attempt string becoming authority or new plan overriding committed turn. | Provider adapter/coordinator. |
| Pending physical roll duplicate | Same confirmation ID/value; then conflicting value | One immutable resolution; exact retry returns it; conflict/reused roll rejects. | Number without pending request or double damage. | Roll resolver. |
| Forged roll effect | Existing/failed roll with changed target, amount or fresh/reused effect ID | Exact authorized effect tuple is required and consumed once; mismatch/reuse has zero mutation. | Existence-only `resolution_id` authorizing arbitrary damage/heal/condition. | Roll resolver/kernel. |
| Forged consequence identity | Candidate supplies `instance_id` or generic consequence body | Closed operation rejects it; server derives identity from pinned template + causal command/transition. | Fresh attacker-chosen IDs multiplying one cause. | Validator/kernel. |
| Enemy retry | Crash/retry around world roll | Persisted face/modifier/total/result reused and public. | Reroll on retry or hidden modifier. | Kernel/RNG adapter. |
| Projection secret canary | Inject private truth/plan/transcript/unknown field into any output candidate | Publication fails closed; no unsafe bytes; last safe batch/cursor retained; safe error code only. | Denylist deletion or admin/narrator leak. | Projector/security. |
| Mixed projection family | Deliver table vN and scene/admin vN−1 as one update | Browser rejects/makes no cursor advance, then obtains full current family. | Partial mixed-version render. | Projection/browser. |
| Wrong classic actor | Table action or phase-end from an actor other than the persisted initiative cursor | Durable rejection; cursor/resources/world unchanged; correct actor advances deterministically and wrap starts the next round. | Side-phase admission logic silently governing classic mode. | Tactical scheduler. |
| Render failure/disconnect | After receive, before render ack | Cursor stays at last successfully rendered batch; reconnect full-snapshots latest safe state. | Ack on receipt or skipped batch. | Browser/projection. |
| Reproject/audio retry | After committed world result | Same batch/line may replay by ID; aggregate/world versions unchanged. | Duplicate movement/damage/reveal. | Admin/presentation. |
| Simultaneous ending predicates | Two endings true | Unique higher authored priority wins; equal top priority is authoring error or explicit `mixed`. | Iteration-order choice. | Definition linter/kernel. |
| Critical carrier unavailable | NPC dead/absent or authored location unavailable | At least one eligible durable alternate route remains for each mandatory fact. | Soft-lock hidden by blanket “revealed” state. | Definition linter/R9. |

The synthetic probe exercises the named core subset of M1, M2, M5 and M6 plus six M3 profile records; it does not exercise the six profiles' class mechanics. Real browser timing, authored-campaign exhaustiveness, voice/audio, full rules closure, balance, and player enjoyment remain R5/R6/R9/R10 or implementation evidence.
