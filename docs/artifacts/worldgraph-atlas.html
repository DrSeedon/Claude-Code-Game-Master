Сюжет без строковых догадок

Квест связан с действующими лицами и местами явно — можно показать досье и карту, не разбирая описание текста.

consequence triggers quest / effect

Мир действует сам

Отложенное событие тикает вместе со временем, а затем меняет цель, состояние или запускает эффект.

recipe requires material

Крафт и зависимости

Рецепт требует материалы и создаёт предмет; знания могут быть связаны через known_by, а продавцы — через sells.

module config interprets core node

Модуль без второго мира

Firearms читает weapon/armor, Mass Combat — creature-шаблоны. Конфиг меняет трактовку, но сущности не дублируются.

05

Путь одной команды

Модель не «помнит», что нанесла урон. Она просит движок выполнить действие, а рассказывает результат только после успешной транзакции.

01 / intent

Решение DM

«Морпех стреляет в зерглинга полным автоматом».

02 / route

CORE tool

Команда атаки получает участника, цель и режим действия.

03 / compose

Модули

Активный provider добавляет очереди, PEN/PROT или массовые группы.

04 / mutate

WorldGraph

Находит узлы, считает результат и меняет HP/боезапас.

05 / commit

Repository

Lock, проверка revision, временный файл и атомарная замена.

06 / project

Dashboard

Игрок получает безопасную проекцию, а DM — фактический результат.
