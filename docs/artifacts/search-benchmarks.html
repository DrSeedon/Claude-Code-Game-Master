Что из этого переносится на прод

  • Бюджет ходов двигает скор сильнее, чем бренд движка. 1→25 ≈ ×2 качество при ×2.5–7 цене.
  • Движок Perplexity на OR дешевле Parallel при почти том же Opus (89% / $0.99 vs 88.8% / $2.42).
  • Plugin-режим (один поиск заранее) на BrowseComp мёртв: 11–12%.
  • Vendor Agent «в 2 раза лучше Sonar» — их маркетинг на своих пресетах. На OR тот же индекс как engine уже даёт Flash 77% без Agent API.
